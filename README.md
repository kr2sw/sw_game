# SW Game

20개의 브라우저 기반 웹 게임 컬렉션. 설치 불필요, HTML/CSS/JS만으로 구현.

## How to Run

```bash
# Python HTTP 서버로 실행
python -m http.server 8080

# 또는 start_server.bat 더블클릭 (Windows)
```

브라우저에서 `http://localhost:8080` 접속

## Features

- 모든 게임 모바일 터치 지원
- 반응형 디자인
- 다크 테마 UI
- 설치 불필요 (纯 HTML/CSS/JS)
- 각 게임별 점수/레벨 시스템
- CPU AI opponents (Tic Tac Toe, Pong 등)

## Tech Stack

- HTML5 Canvas
- CSS3
- Vanilla JavaScript
- Python HTTP Server (로컬 실행용)
